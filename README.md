# Gridiron Blitz 3D

A self-contained, buildless 3D American-football game. The simulation engine
runs all game logic on a 2D plane; a Three.js layer renders it in 3D.

This is the "real project" evolution of the original single-file
`gridiron-blitz-3d.html` (kept in the repo for reference). Key changes:

- **No CDN.** Three.js r128 and the example loaders are vendored under `vendor/`,
  so the game runs offline.
- **Rigged GLTF players, generated from code.** `assets/gridiron_player.glb` is
  sculpted, meshed, rigged and textured by `tools/player/build.mjs` — no external
  asset, no licence to credit. One model is cloned per entity with per-team colours,
  the player's real roster number and surname painted onto the jersey, and
  per-player variation (skin tone, build, visor, gloves, cleats). The skeleton uses
  Mixamo bone names and bone frames, so the game's procedural poses drive it.

## Run it

The game is just static files. Serve the folder and open `index.html`:

```bash
npm install        # only needed to (re)build the model or use the bundled server
npm run serve      # http-server on http://localhost:8088
# then open http://localhost:8088/index.html
```

Any static file server works; `index.html` only needs `vendor/` and `assets/`
next to it.

## Rebuild the player model

`assets/gridiron_player.glb` is generated, not hand-authored, and the build has no
dependencies beyond Node (it runs where npm cannot):

```bash
node tools/player/build.mjs            # ~2.5 min, writes assets/gridiron_player.glb
node tools/adopt-model.mjs assets/gridiron_player.glb   # grade it
```

How it is made, one file per stage in `tools/player/`:

- `rig.mjs` — 65-bone skeleton: Mixamo names, Mixamo local frames (the game's pose
  code was measured on them), five-finger hands. Sculpted in an A-pose (`bind`),
  shipped with the arms down (`rest`).
- `body.mjs` — every part (head, arms, gloves, jersey over shoulder pads, pants,
  socks, cleats, helmet, facemask, visor, chin strap) as a signed distance field
  laid out on the joints.
- `mesher.mjs` / `qem.mjs` — surface nets with a narrow-band evaluator, manifold
  repair, and quadric-error decimation to a per-part triangle budget; exact cuts
  along material boundaries (collar and sleeve trim, belt, pants).
- `weights.mjs` — skin weights from the skeleton; the shoulder pads stay rigid.
- `decals.mjs` — number and nameplate patches projected onto the jersey.
- `textures.mjs` — tiling knit/twill/rib/grip normal maps; `anim.mjs` — idle clip.
- `glb.mjs` / `png.mjs` — the file writers.

`tools/player/view.html` + `shoot.mjs` render it under the game's lights for
checking (`node tools/player/shoot.mjs assets/gridiron_player.glb out/`).

## Layout

```
index.html              the game (engine + 3D renderer)
gridiron-blitz-3d.html  original single-file version (reference)
vendor/                 three.min.js, GLTFLoader, SkeletonUtils, BufferGeometryUtils, GLTFExporter
assets/gridiron_player.glb  the player, generated by tools/player/build.mjs
tools/player/           the generator (see above)
tools/adopt-model.mjs   grades any player GLB against PLAYER_MODEL_PROMPT.md
assets/player.glb       older primitive player (unused; tools/build-player.cjs)
```
